# Strongman Simulator GUI

Strongman Simulator GUI is a Roblox script that adds a user interface to the Strongman Simulator game. It provides players with a graphical interface to interact with the game, displaying their score, energy, and strength attributes, and allowing them to start the game and perform fast workouts.

## Install

1. Download the Strongman Simulator GUI script from the GitHub repository.
2. Open your Roblox Studio project.
3. Place the `StrongmanSimulatorGUI.server.lua` script in the StarterPlayerScripts folder.
4. Place the `StrongmanSimulatorLogic.module.lua` script in the ReplicatedStorage folder.

## Use

1. Start the game by clicking the "Start Game" button on the GUI.
2. Perform fast workouts to increase your strength by clicking the "Fast Workout" button. Each fast workout consumes 20 energy and increases your strength by 5. There is a 1-minute cooldown between fast workouts.
3. Monitor your score, energy, and strength attributes displayed on the GUI.
